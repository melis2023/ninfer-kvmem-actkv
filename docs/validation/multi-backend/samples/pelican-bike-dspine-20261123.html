How it holds together

Four parts,
one smooth ride

从车轮到头盔，每一个部件都在为同一件事服务：让这只大嘴鸟稳稳地、飞快地、优雅地往前冲。

  1. 01

    双轮驱动

    前后两个辐条轮以相同角速度旋转，链条把踏板的力传递到后轴，形成持续向前的推力。

  2. 02

    三角车架

    主三角形由座管、下管和上管构成，是整台车最刚性的部分，负责承受骑手的全部重量。

  3. 03

    重心与平衡

    鹈鹕把身体前倾、手臂伸向车把，将重心压在前叉上方，从而在高速中保持稳定的直线轨迹。

  4. 04

    安全装备

    一顶亮黄色头盔罩住头顶，配合低姿态骑行，把每一次颠簸都变成一段可控的旅程。
